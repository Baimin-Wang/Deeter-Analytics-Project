# Included data

`cache/` currently contains 433 downloaded CSVs for the 448-name universe; 431 pass the loader's minimum-history check. The original 56 files cover approximately 2024-01-02 through 2026-09-21. Most expanded downloads begin around 2024-04-26 and run through 2026-09-21, which is enough for the default two-year Thursday/Friday evidence window after the baseline warm-up. Two files contain only one row and 15 tickers have no usable file. These files are a research cache, not a point-in-time market-data database. Their documented source is Yahoo Finance's public chart endpoint; this revision did not independently verify the cached prices against another source.

The schema is `date,open,high,low,close,volume`. The loader validates finite values, positive prices, nonnegative volume, unique dates and OHLC bounds. New downloads normalize timestamps to daily dates before returning and caching, so live and cached paths use the same index. Current-UTC-date bars are excluded from downloads conservatively. A fully missing session still requires calendar-aware auditing.

Use `--offline --end 2026-09-21` to reproduce the cached fixture without changing it. The expanded download currently has 431 usable names; 15 universe tickers did not return a usable history, and two additional cache files contain only one row and are rejected by the 80-row minimum. Offline mode reports all 17. Without `--offline`, the loader may download/refresh the requested universe over the public Yahoo chart endpoint; allow time for hundreds of symbols and inspect the skipped-symbol report. Recent cache data can be up to three calendar days behind the requested end; actual dates are reported. There is no API key. Internet access and endpoint availability are required only for refresh.

The old backtest default used 26 Thursday/Friday pairs, roughly six months, because the original take-home prototype was designed to finish quickly with 56 symbols. That is too short for a directional screen: it can be dominated by one market regime and gives very few setups. The default is now 104 pairs, roughly two years, subject to the available history. Pass `--weeks 156` for a longer request; the current fixture begins in January 2024 and most expanded downloads begin in April 2024, so the earliest requested dates may have no usable baseline and will appear in `coverage.csv`.

The raw quote fields do not provide a controlled dividend/split or point-in-time revision policy. No adjusted-close series is used. Calling this a saved snapshot does not imply it contains historical constituent membership, delisted names, original publication timestamps or unrevised prices. Production research needs a verified corporate-action policy and historical universe.
